# amyAMP v1.0.0

Public release of the amyAMP BiGAN peptide generator.

## Install

```bash
git clone https://github.com/anupkprasad/amyAMP.git
cd amyAMP
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
./generate_peptides.sh
```

## Contents

- Pretrained models in `model_saved/`
- Training FASTAs and PC6 table in `data_master/`
- Analysis scripts under `scripts/`
- Apache-2.0 license, `CITATION.cff`, `CONTRIBUTING.md`

## Disclaimer

Computational designs for research use only — not approved therapeutics. Experimental validation is required.
